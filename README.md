An end-to-end machine learning web application that predicts whether water is safe for drinking using physicochemical water quality parameters and ensemble learning techniques.

---

## Overview

This project combines machine learning, data preprocessing, feature engineering, and an interactive web interface to analyze water quality and predict potability in real time.

The system allows users to enter water parameters through a clean Streamlit interface and instantly receive a prediction generated by a trained ensemble model. Perfect for water quality monitoring, environmental analysis, and educational purposes.

## Installation & Setup

### Prerequisites

- Python 3.8 or higher
- pip or conda package manager

### Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hassan-ali786/water-quality-prediction-ml.git
   cd water-quality-prediction-ml
   ```

2. **Create a virtual environment (recommended):**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the application:**
   ```bash
   streamlit run app/app.py
   ```

5. **Open in browser:**
   - The app will automatically open at `http://localhost:8501`

## Usage Guide

### Web Application Features

1. **Home Page (app.py)**
   - Overview of the project
   - Key statistics and model information
   - Links to other pages

2. **EDA Page (pages/1_EDA.py)**
   - Exploratory Data Analysis visualizations
   - Feature distributions and correlations
   - Water quality insights

3. **Prediction Page (pages/2_Prediction.py)**
   - Interactive input form for water parameters
   - Real-time prediction results
   - Prediction confidence and explanation

### How to Make a Prediction

1. Navigate to the **Prediction** page
2. Enter the following parameters:
   - **pH:** Acidity/alkalinity level (0-14)
   - **Hardness:** Mineral concentration in mg/L
   - **Solids:** Dissolved solid particles in ppm
   - **Chloramines:** Disinfectant level in ppm
   - **Sulfate:** Sulfate concentration in mg/L
   - **Conductivity:** Electrical conductivity in μS/cm
   - **Organic Carbon:** Contamination level in ppm
   - **Trihalomethanes:** Chemical byproducts in μg/L
   - **Turbidity:** Water clarity in NTU

3. Click **"Predict"** to get results
4. The model will output: **Potable** (Safe) or **Not Potable** (Unsafe)

## Dataset Features

| Feature | Description | WHO Safe Range |
|---|---|---|
| pH | Acidity or alkalinity level | 6.5 – 8.5 |
| Hardness | Mineral concentration in water | < 300 mg/L |
| Solids | Dissolved solid particles | < 500 ppm |
| Chloramines | Water disinfectant level | < 4 ppm |
| Sulfate | Sulfate concentration | < 250 mg/L |
| Conductivity | Electrical conductivity | < 400 μS/cm |
| Organic Carbon | Organic contamination level | < 2 ppm |
| Trihalomethanes | Chemical byproducts | < 80 μg/L |
| Turbidity | Water clarity level | < 1 NTU |

### Dataset Information

- **Source:** [Water Potability Dataset - Kaggle](https://www.kaggle.com/adityakadiwal/water-potability)
- **Size:** ~3,276 samples with 10 features
- **Class Distribution:** Potable vs Non-Potable (imbalanced)
- **Missing Values:** Handled using mean imputation
- **Train/Test Split:** 80/20

---

## Machine Learning Pipeline

### Data Preprocessing

- **Missing Value Handling:** Mean imputation for missing values
- **Data Cleaning:** Removal of outliers and validation
- **Feature Scaling:** StandardScaler normalization (mean=0, std=1)

### Feature Engineering

- Created interaction-based features to capture relationships between parameters
- Polynomial features for non-linear patterns
- Domain-knowledge features based on WHO standards

### Handling Imbalanced Data

- **SMOTE (Synthetic Minority Over-sampling Technique)** applied to balance potable and non-potable classes
- Improved model generalization and reduced bias

### Model Training

- **Hyperparameter Tuning:** GridSearchCV with 5-fold cross-validation
- **Performance Evaluation:** Accuracy, Precision, Recall, F1-Score, AUC-ROC
- **Ensemble Learning:** Stacking for final prediction optimization

### Final Workflow

```
Raw Data
    ↓
Data Cleaning & Validation
    ↓
Feature Engineering
    ↓
SMOTE Balancing
    ↓
Feature Scaling (StandardScaler)
    ↓
Model Training (with GridSearchCV)
    ↓
Stacking Ensemble
    ↓
Prediction Output
```

## Training the Model

To retrain the model with your own data or modifications:

```bash
python model/train_model.py
```

### What This Script Does:
1. Loads the water potability dataset
2. Performs data preprocessing and feature engineering
3. Applies SMOTE for class balancing
4. Trains individual models (Random Forest, XGBoost, Gradient Boosting)
5. Creates and trains the stacking ensemble
6. Saves the trained model and scaler to pickle files
7. Displays cross-validation and test performance metrics

**Training Time:** ~2-5 minutes (depends on hardware)

---

## Model Evaluation

The model is evaluated using:

- **Accuracy:** Overall correctness of predictions
- **Precision:** True positives / (True positives + False positives)
- **Recall:** True positives / (True positives + False negatives)
- **F1-Score:** Harmonic mean of Precision and Recall
- **AUC-ROC:** Area under the Receiver Operating Characteristic curve
- **Confusion Matrix:** True positives, false positives, true negatives, false negatives

Check the `notebooks/eda.ipynb` for detailed evaluation plots and analysis.

## Troubleshooting

### Common Issues & Solutions

| Issue | Solution |
|---|---|
| **ModuleNotFoundError** | Run `pip install -r requirements.txt` to install all dependencies |
| **Port 8501 already in use** | Run `streamlit run app/app.py --server.port 8502` to use a different port |
| **Model file not found** | Ensure `model/model.pkl` exists; run `python model/train_model.py` to retrain |
| **ImportError for SMOTE** | Install with `pip install imbalanced-learn` |
| **App runs slowly** | First load caches the model; subsequent predictions are faster |
